# 日檢 N4 考前衝刺（可切換 N3）

JLPT 日本語能力試驗 N4 的考前練習網站，準備 2026/12/6（日）第 2 回；右上角可以切換到 N3 模式，功能相同、題庫另外一套。文字語彙、文法、讀解、聽解（瀏覽器念日文）、單字卡、文法速查和錯題本，每題附中文翻譯與解析。手機優先、純靜態（單一 HTML，CSS 和 JS 都寫在檔內），不需要建置工具或後端。

> **非官方網站。** 題目、單字和文法說明都是自編練習內容，不是日本語能力試驗的官方試題。考試規定以准考證和 LTTC 公告為準。

## 功能

- **迷你模考**：約 25 題，照正式順序（語彙 → 文法 → 讀解 → 聽解），計時，交卷後才看解析；結果分「言語知識・讀解」和「聽解」兩區
- **四科分題型練習**：每次 10 題（讀解以整篇文章為單位），沒做過的優先、再來是答錯的
  - 文字・語彙：漢字読み 30、表記 25、文脈規定 30、言い換え類義 18、用法 12
  - 文法：文法形式の判断 53、文の組み立て（★）15、文章の文法 2 篇 8 題
  - 讀解：短文 4 篇、中篇 2 篇 6 題、情報検索 2 篇 4 題
  - 聽解：課題理解 6、ポイント理解 6、発話表現 6、即時応答 12（用瀏覽器的日文語音念，可切換「慢速」（0.75 倍），作答前可按「顯示原文」）
- **單字卡**：193 個 N4 常考單字，依詞性分類，可只翻「還不熟」的，可念出讀音
- **文法速查**：70 條 N4 文法，意思、接續、例句（可念）、易錯提醒，可搜尋、依分類篩選
- **錯題本**：答錯自動收進來，答對一次就拿掉
- **考試資訊**：科目時間、題型、合格標準、台灣考區公告（含 LTTC 網站事件的提醒）、考前清單、距離考試天數
- **假名開關**：題目漢字上方標讀音；解析裡的完整句子一律標讀音
- **點字查詢**：題目、文章、聽解原文、解析、單字卡和文法例句裡的日文單字都可以點。跳出的說明包括原形、讀音、詞性、中文和說明；如果文中是變化後的形式，會列出變化步驟（例如「行かなければなりません」：ない形 → なければなりません）。還可以念出讀音、加入生字本，或連到 Weblio 日中辭典查更多。手機上從底部滑出，電腦上顯示在單字旁邊。
  - 為了不直接看到答案，作答前不能查選項和畫底線的字；迷你模考交卷前完全不能查，交卷後可在「逐題檢討」裡查。
  - 漢字讀法和表記這兩種題型的選項本身就是讀音和寫法，所以不能點。
- **生字本**：點字時按「加入生字本」，會連同出現的句子一起存起來，首頁可以用卡片複習；按「記住了」就會移出生字本。
- **N4／N3 切換**：每個畫面右上角的「N4｜N3」。N3 有自己的題庫、單字卡、文法速查、考試資訊（時間 30／70／40 分；合格 95/180，言語知識・讀解・聽解三科各至少 19/60）、考場策略和迷你模考（約 30 題，結果分言語知識、讀解、聽解三區）。作答紀錄、錯題本、生字本和設定共用；模考最佳成績分開記。
  - N3 題庫：漢字読み 20、表記 15、文脈規定 20、言い換え類義 12（選意思最接近的詞）、用法 8；文法形式の判断 35、文の組み立て 12、文章の文法 2 篇 9 題；短文 4 篇、中文 2 篇 6 題、長文 1 篇 4 題、情報検索 2 篇 4 題；課題理解 5、ポイント理解 5、概要理解 4、発話表現 5、即時応答 10，共 178 題。單字卡 186 個、文法 64 條。
  - 「概要理解」照正式考試：先聽整段話，最後才念問題和選項，畫面不印出來（可按「顯示原文」）。
- **介面語言**：每個畫面右上角可切換「中文／日本語」。只有介面（按鈕、標題、題型說明、考試資訊、考前清單、考場策略）會換成日文；題目的中文翻譯、解說、單字和文法的中文意思永遠是中文，並標 `lang="zh-Hant"` 保持中文字形
- **深淺色**：右上角可切換淺色／深色；沒選過時跟著系統設定。選擇存在瀏覽器，下次打開時在畫面出現前就套用（`<head>` 裡的小段 script）
- 練習紀錄只存在使用者自己的瀏覽器（localStorage），不收集任何資料

## 三種版面（同一個檔案，用寬度切換）

| 寬度 | 版面 |

## 題庫格式

所有日文字串共用這些標記：

| 標記 | 意思 |
|---|---|
| `{漢字:かんじ}` | 假名標在漢字上方 |
| `[ ... ]` | 題目畫底線的詞 |
| `（　）` | 填空的位置 |
| `＿＿＿`、`＿★＿` | 句子重組的四個空格，★ 是要問的位置 |
| `［1］` | 文章裡的編號空格 |

- 語彙、文法題（`Q_KANJI`、`Q_HYOKI`、`Q_BUNMYAKU`、`Q_IIKAE`、`Q_YOHO`、`Q_BUNPO`、`Q_NARABE`）一行一題：`id|題目|正解;錯1;錯2;錯3|中文翻譯|解說`。
- **正確答案一律寫在第一個**，畫面上會打亂順序。句子重組的選項照「正確句子的順序」寫。
- 讀解和文章填空在 `PASSAGES`，聽解在 `LISTEN`（物件格式，說明寫在陣列上方）。選項本身有順序時（例如 A–D、金額）加 `fixed:[顯示順序]`。
- 單字卡 `VOCAB_SRC`：`單字|讀音|詞性|中文|例句|例句中文`；文法 `GRAMMAR_SRC`：`分類|文法|中文意思|接續|例句|例句中文|提醒`。
- 題目的 `id` 不要改：作答紀錄和錯題本用 id 記錄。
- **N3 題庫**用同樣的格式，名稱前面加 `N3_`（`N3_Q_KANJI`…`N3_GRAMMAR_SRC`、`N3_PASSAGES`、`N3_LISTEN`），id 都以 `3` 開頭，和 N4 不能重複。N3 多兩種題型：長文 `cho`（文章，放在 `N3_PASSAGES`）和概要理解 `gaiyo`（聽解，格式同課題理解：`intro`、`lines`、`q`、四個選項）。
- 兩個級數在 `LEVELS`（`buildLevel()` 建立）；`useLevel()` 會把 `ITEMS`、`BY_TYPE`、`VOCAB`、`GRAMMAR`、`TYPES`、`SECS`、`SEC_TYPES` 換成目前級數的。題型、科目時間在 `TYPES_N4`／`TYPES_N3`、`SECS_N4`／`SECS_N3`，考場策略在 `TIPS_N4`／`TIPS_N3`。

### 點字查詢的字典

在 `index.html` 第二個 `<script>` 的 `JDICT_SRC`，一行一個詞：`見出し(/其他寫法)|読み|類別|中文|說明`。約 1,600 條，涵蓋 N4 和 N3 的題庫、文章、聽解、單字卡和文法例句裡的每個詞。

- 類別決定動詞和形容詞怎麼還原：`v1` 一段、`v5` 五段、`vk` 来る、`vs` する（名詞加 `vs` 就能接する）、`adj-i`、`adj-na`；其他如 `n`、`adv`、`prt`、`exp`、`ctr`（量詞，只在數字後面才比對）、`name`、`gram`（文法題選項片段，整個選項只有它時才算）。
- 有漢字的詞會自動用讀音當作平假名寫法，但排序在明確寫出的寫法之後。
- 斷詞以 `{漢字:かな}` 為不能切開的單位，選「詞數最少」的切法；同一個寫法有幾個讀音時，用假名標音挑對的那個。
- **新增或修改題目後**，在瀏覽器主控台執行 `dictMissing()`，會列出字典裡還找不到的片段，補進 `JDICT_SRC` 直到回傳空陣列。

改完題庫可以用 Node 檢查兩個級數的格式、選項數、標記和假名是否齊全（檢查腳本不在 repo 裡，邏輯是：每行欄位數、四個選項不重複、底線／空格各一個、句子重組四格一顆星、漢字都有 `{漢字:讀音}`、id 不重複）。

## 本機儲存（localStorage）

key `jlpt-n4-review-v1`：作答統計 `stats`、錯題 `wrong`、單字卡「記住了」`known`、考前清單 `checks`、假名開關 `furi`、模考最佳成績 `best`（N4）和 `best3`（N3）、級數 `level`（`n4`／`n3`）、介面語言 `lang`（`zh`／`ja`）、外觀 `theme`（`light`／`dark`，沒有就跟系統）、聽解慢速 `slow`、生字本 `mywords`（字典條目 key → 出現的句子）。題庫大改時換 key 的版本號（`<head>` 裡套用主題的 script 也要一起改）。「清除練習紀錄」會保留級數、語言、外觀、假名、慢速、考前清單和生字本。字典條目的 key 是「見出し|読み」，改見出し或讀音會讓已存的生字本對不到。

新增介面文字時用 `tx("中文", "日本語")`；題型、科目的說明是 `[中文, 日本語]` 陣列，用 `L2()` 取。
