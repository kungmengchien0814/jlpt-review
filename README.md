# 日檢考前衝刺（N5～N1）

JLPT 日本語能力試驗的考前練習網站，原本為了準備 2026/12/6（日）第 2 回的 N4，現在右上角的下拉選單可以切換 N5、N4、N3、N2、N1，每個級數各有一套題庫，功能相同。文字語彙、文法、讀解、聽解（瀏覽器念日文）、單字卡、文法速查和錯題本，每題附中文翻譯與解析。手機優先、純靜態（N4 題庫和程式在 `index.html`，其他級數的題庫各一個 `.js` 檔，切到那一級才下載），不需要建置工具或後端。

> **非官方網站。** 題目、單字和文法說明都是自編練習內容，不是日本語能力試驗的官方試題。考試規定以准考證和 LTTC 公告為準。

## 功能

- **級數切換**：每個畫面右上角的級數按鈕（例如「N4 ▾」），點一下打開選單選 N5～N1。N4 內建在頁面裡；其他級數第一次選時會下載該級的題庫檔，載入失敗會顯示「再試一次／回到原本的級數」。選過的級數會記住，下次打開直接進那一級。
- **迷你模考**：照正式順序（語彙 → 文法 → 讀解 → 聽解），計時，交卷後才看解析。題數和計分區照各級：
  - N5、N4：約 25 題，結果分「言語知識・讀解」和「聽解」兩區
  - N3：約 30 題；N2：約 30 題；N1：約 28 題，結果分「言語知識」「讀解」「聽解」三區
- **四科分題型練習**：每次 10 題（讀解以整篇文章為單位），沒做過的優先、再來是答錯的
- **單字卡、文法速查、錯題本、考試資訊、考前清單、考場策略**：每個級數各自一套
- **聽解**：用瀏覽器的日文語音念，可切換「慢速」（0.75 倍），作答前可按「顯示原文」
  - 「概要理解」（N3～N1）和「統合理解」1、2 番（N2、N1）照正式考試：問題和選項只用聽的，畫面不印出來
  - 「統合理解」3 番（N2、N1）：先聽說明和兩人討論，畫面只印選項，兩個問題拆成連續兩題；第二題只重念問題
- **假名開關**：題目漢字上方標讀音；解析裡的完整句子一律標讀音
- **點字查詢**：題目、文章、聽解原文、解析、單字卡和文法例句裡的日文單字都可以點。跳出的說明包括原形、讀音、詞性、中文和說明；如果文中是變化後的形式，會列出變化步驟（例如「行かなければなりません」：ない形 → なければなりません）。還可以念出讀音、加入生字本，或連到 Weblio 日中辭典查更多。手機上從底部滑出，電腦上顯示在單字旁邊。
  - 為了不直接看到答案，作答前不能查選項和畫底線的字；迷你模考交卷前完全不能查，交卷後可在「逐題檢討」裡查。
  - 漢字讀法和表記這兩種題型的選項本身就是讀音和寫法，所以不能點。
- **生字本**：點字時按「加入生字本」，會連同出現的句子一起存起來，首頁可以用卡片複習；按「記住了」就會移出生字本。五個級數共用一本。
- **介面語言**：每個畫面右上角可切換「中文／日本語」。只有介面（按鈕、標題、題型說明、考試資訊、考前清單、考場策略）會換成日文；題目的中文翻譯、解說、單字和文法的中文意思永遠是中文，並標 `lang="zh-Hant"` 保持中文字形
- **深淺色**：右上角可切換淺色／深色；沒選過時跟著系統設定。選擇存在瀏覽器，下次打開時在畫面出現前就套用（`<head>` 裡的小段 script）
- 練習紀錄只存在使用者自己的瀏覽器（localStorage），不收集任何資料

## 題庫格式

所有日文字串共用這些標記：

| 標記 | 意思 |
|---|---|
| `{漢字:かんじ}` | 假名標在漢字上方 |
| `[ ... ]` | 題目畫底線的詞 |
| `（　）` | 填空的位置 |
| `＿＿＿`、`＿★＿` | 句子重組的四個空格，★ 是要問的位置 |
| `［1］` | 文章裡的編號空格 |
| `§A`、`§B` | 文章段落開頭寫 `§` 的是統合理解 A、B 兩篇的標記 |

- 語彙、文法題（`Q_KANJI`、`Q_HYOKI`、`Q_BUNMYAKU`、`Q_IIKAE`、`Q_YOHO`、`Q_BUNPO`、`Q_NARABE`，N2 另有 `Q_GOKEI` 語形成）一行一題：`id|題目|正解;錯1;錯2;錯3|中文翻譯|解說`。
- **正確答案一律寫在第一個**，畫面上會打亂順序。例外是句子重組：選項照「正確句子的順序」寫，答案是 ★ 那一格的選項（程式從 `＿★＿` 的位置算出來）。
- 讀解和文章填空在 `PASSAGES`，聽解在 `LISTEN`（物件格式，說明寫在陣列上方）。選項本身有順序時（例如 A–D、金額）加 `fixed:[顯示順序]`。
- 聽解的說話者：`m` 男、`f` 女、`m2`／`f2` 第二位男女（三人對話）、`n` 旁白。統合理解 `togoc`：沒寫 `printed` 的是 1、2 番（問題選項只用聽的）；`printed:true` 加 `qs:[{q, o, note}, …]` 是 3 番，一段話兩個問題。
- 單字卡 `VOCAB_SRC`：`單字|讀音|詞性|中文|例句|例句中文`；文法 `GRAMMAR_SRC`：`分類|文法|中文意思|接續|例句|例句中文|提醒`。
- 題目的 `id` 不要改：作答紀錄和錯題本用 id 記錄。N4 的 id 用英文字母開頭；其他級數用級數數字開頭（`5…`、`3…`、`2…`、`1…`），不能重複。
- **其他級數的題庫**在 `levels/<級數>.js`，常數名稱前面加級數（例如 `N2_Q_KANJI`、`N2_PASSAGES`），檔案最後登記到 `window.JLPT_LEVEL_DATA.<級數>`。**改了任何 `levels/*.js`，要把 `index.html` 裡的 `DATA_V` 換成新的版本號**，不然手機可能讀到舊的快取。
- 各級的題型、科目時間、考試時間、合格標準、計分區、模考和混合練習的組成、考場策略都在 `index.html` 的 `LEVEL_CONF`（`TYPES_N5`…`TYPES_N1`、`SECS_*`、`TIPS_*`）；`useLevel()` 會把 `ITEMS`、`BY_TYPE`、`VOCAB`、`GRAMMAR`、`TYPES`、`SECS`、`SEC_TYPES` 換成目前級數的。

### 點字查詢的字典

在 `index.html` 第二個 `<script>` 的 `JDICT_SRC`，一行一個詞：`見出し(/其他寫法)|読み|類別|中文|說明`。約 3,000 條，涵蓋五個級數的題庫、文章、聽解、單字卡和文法例句裡的每個詞（字典一律放在頁面裡，沒有分檔）。

- 類別決定動詞和形容詞怎麼還原：`v1` 一段、`v5` 五段、`vk` 来る、`vs` する（名詞加 `vs` 就能接する）、`adj-i`、`adj-na`；其他如 `n`、`adv`、`prt`、`exp`、`ctr`（量詞，只在數字後面才比對）、`pref`、`suf`、`aux`、`name`、`gram`（文法題選項片段，整個選項只有它時才算）。
- 同一個「見出し|読み」只會有一條；後面再寫一次同樣的詞，只會把其他寫法併進去，類別和中文不會改。
- 有漢字的詞會自動用讀音當作平假名寫法，但排序在明確寫出的寫法之後。
- 斷詞以 `{漢字:かな}` 為不能切開的單位，選「詞數最少」的切法；同一個寫法有幾個讀音時，用假名標音挑對的那個。
- **新增或修改題目後**，在瀏覽器主控台執行 `await loadAllLevels()`，再執行 `dictMissing()`，會列出字典裡還找不到的片段，補進 `JDICT_SRC` 直到回傳空陣列。

檢查腳本放在 `notes/tools/`（只在本機）：`checkall.js` 檢查五個級數的格式、選項數、標記、假名和 id，`coverall.js` 用頁面自己的字典跑一遍所有日文，`dbg.js` 看某句話怎麼斷詞，`assemble.py` 把分段寫的題庫組成 `levels/*.js`，`dictadd.py` 把新詞條加進 `JDICT_SRC`。

## 本機儲存（localStorage）

key `jlpt-n4-review-v1`：作答統計 `stats`、錯題 `wrong`、單字卡「記住了」`known`、考前清單 `checks`、假名開關 `furi`、模考最佳成績 `best`（N4）、`best5`、`best3`、`best2`、`best1`、級數 `level`（`n5`～`n1`）、介面語言 `lang`（`zh`／`ja`）、外觀 `theme`（`light`／`dark`，沒有就跟系統）、聽解慢速 `slow`、生字本 `mywords`（字典條目 key → 出現的句子）。題庫大改時換 key 的版本號（`<head>` 裡套用主題的 script 也要一起改）。「清除練習紀錄」會保留級數、語言、外觀、假名、慢速、考前清單和生字本。字典條目的 key 是「見出し|読み」，改見出し或讀音會讓已存的生字本對不到。

錯題本只會清掉「該級已載入、題目卻已不存在」的 id，還沒載入的級數不受影響。

新增介面文字時用 `tx("中文", "日本語")`；題型、科目的說明是 `[中文, 日本語]` 陣列，用 `L2()` 取。
